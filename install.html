How to install it
  1. Tap Download for Android, then open the downloaded file.
  2. If your phone says it can't install apps from this source, tap Settings, turn on Allow from this source, then go back.
  3. Tap Install.
  4. If you see a warning about an unrecognized app, tap More details, then Install anyway. That's normal for a test version that isn't in the Play Store yet.
  5. Open Mahjong School from your home screen.

For the web version, open this page in Chrome, tap the ⋮ menu, then Install app or Add to Home screen.

For your phone

iPhone and iPad

The test version installs from Safari in a few taps. No download, no settings to change.

For the easiest install, open this page in Safari. Copy the link and paste it into Safari.
  1. Open this page in Safari.
  2. Tap the Share button Share at the bottom of the screen (on iPad, it's at the top).
  3. Scroll down and tap Add to Home Screen.
  4. Tap Add in the top corner.
  5. Open Mahjong School from your home screen. It runs full screen and works offline.
